# eishexac/homebrew-tap

Homebrew tap for eishexac's tools.

## Install

```sh
brew install eishexac/tap/mousekeys
```

Before the first tagged release, build from the development branch:

```sh
brew install --HEAD eishexac/tap/mousekeys
```

## Formulae

| Formula | Description | License |
|---|---|---|
| `mousekeys` | Keyboard-driven mouse control (QMK-style layers) as a native macOS daemon. | MIT |

Each formula declares its own `license`. A formula being distributed here does
not imply an open-source grant — check the individual formula's `license` field
and its upstream repository for terms of use.

## Notes

- This tap is public and installs without authentication.
- Private/personal formulae live in a separate tap (`eishexac/lab`).
